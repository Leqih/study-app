A small surface tile with one number and its label, used three across for the summary of a bake or a week.

**Markup.** `<div class="stats">` holding three `<div class="stat cut"><b>50</b><span>minutes</span></div>`.

**Rules.**
- The number is `title3` with tabular figures; the label is `caption` in `text-2`, lower case, plural noun.
- Always three tiles in a row, never one alone or a row with a gap.
- Show only numbers the user acted on (minutes, exits, goals). No filler stats.
