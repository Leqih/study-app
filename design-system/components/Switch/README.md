A 51 × 31 capsule switch with a round thumb, plus the 24px circular check it pairs with.

**Markup.** `<button class="switch rounded" role="switch" aria-checked="true|false" aria-label="…">`. Check: `<span class="check rounded" aria-checked>` holding a white tick when checked. Radios use the same circle.

**Rules.**
- On is `brand` pink with the thumb right; off is `line-strong`. The thumb position carries the state.
- A switch applies at once; never pair it with a Save button.
- Checked circles fill black.
